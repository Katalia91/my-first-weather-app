# 🌤️ Weather App

My first weather application built with vanilla JavaScript as part of my early frontend development journey.

The app uses the OpenWeather API to display current weather conditions and a short forecast for a selected city or the user's current location.

## ✨ Features

- Search weather by city
- Detect weather based on current location
- Display current temperature, humidity, pressure and wind speed
- Short weather forecast
- Switch between Celsius and Fahrenheit

## ⚙️ Tech

- HTML
- CSS
- JavaScript
- OpenWeather API
- Axios
